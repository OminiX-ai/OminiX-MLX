**设计依据:** `docs/superpowers/specs/2026-06-04-gemma4-12b-text-mlx-design.md`(§8 M0 结论已回填)。

**M0 已确立、M1 直接采用的事实:**
- 嵌入缩放 `embed_scale = hidden_size**0.5`(=√3840≈61.968)。
- `tie_word_embeddings=true` → 无独立 lm_head;用 `embed_tokens` 反投影。
- `final_logit_softcapping=30.0` → `logits = 30 * tanh(logits/30)`,采样前应用。
- 每层 4 norm + 两残差 + 层末 layer_scalar(已在 `block.rs`)。
- 层类型:5 sliding + 1 full,重复 8 次(`layer_types`,已解析)。
- 全模型参考内部自建**正确因果 mask**(非 M0 dump 的 f32 hack)→ M1 对齐顺带验证 mask 正确性。

**参考(mlx-vlm `Gemma4TextModel.__call__`,镜像之):**
```
h = embed_tokens(inputs) * embed_scale
masks = _make_masks(...)            # full层: causal; sliding层: causal+window(prefill 短序列下二者等价)
for layer, m in zip(layers, masks): h = layer(h, mask=m)   # block.forward

# 外层(Gemma4ForCausalLM): logits = lm_head_or_tied(h); logits = softcap(logits)
```

pub fn make_quantized_embedding(
    weights: &HashMap<String, Array>, prefix: &str, group_size: i32, bits: i32,
) -> Result<nn::QuantizedEmbedding> {
    let weight = get_weight(weights, &format!("{prefix}.weight"))?;
    let scales = get_weight(weights, &format!("{prefix}.scales"))?;
    let biases = get_weight(weights, &format!("{prefix}.biases"))?;
    let inner = nn::Embedding { weight: Param::new(weight) };
    let mut qe = nn::QuantizedEmbedding {
        group_size, bits, scales: Param::new(scales), biases: Param::new(biases), inner,
    };
    qe.freeze_parameters(true);
    Ok(qe)
}

## Task 2: `model.rs` — `Gemma4TextModel` 结构 + `load_model`

**Files:** Create `gemma4-mlx/src/model.rs`; modify `gemma4-mlx/src/lib.rs`.

- [ ] **Step 1: 定义结构 + 加载器**

```rust
//! Gemma 4 full text model: embed (×√hidden) → 48 blocks → final norm → tied lm_head → softcap.
use std::path::Path;
use std::collections::HashMap;
use mlx_rs::{Array, nn};
use crate::block::TransformerBlock;
use crate::config::{ModelArgs, QuantConfig, LayerKind};
use crate::norm::GemmaRmsNorm;
use crate::weights::{load_all_weights, get_weight, make_quantized_embedding};
use crate::error::{Error, Result};

pub struct Gemma4TextModel {
    embed_tokens: nn::QuantizedEmbedding,
    embed_scale: f32,
    layers: Vec<TransformerBlock>,
    norm: GemmaRmsNorm,                 // final RMSNorm (language_model.model.norm.weight)
    final_logit_softcapping: f32,
    layer_types: Vec<LayerKind>,
    sliding_window: i32,
    args: ModelArgs,
}

pub fn load_model(model_dir: impl AsRef<Path>) -> Result<Gemma4TextModel> {
    let dir = model_dir.as_ref();
    let cfg = std::fs::read_to_string(dir.join("config.json"))?;
    let args = ModelArgs::from_config_str(&cfg)?;
    let quant = QuantConfig::from_config_str(&cfg)?
        .ok_or_else(|| Error::Config("expected quantization config".into()))?;
    let weights = load_all_weights(dir)?;

    // embed_tokens: prefix language_model.model.embed_tokens; quant per quant_for.
    let ep = "language_model.model.embed_tokens";
    let (eb, eg) = quant.quant_for(ep);
    let embed_tokens = make_quantized_embedding(&weights, ep, eg, eb)?;

    let mut layers = Vec::with_capacity(args.num_hidden_layers as usize);
    for i in 0..args.num_hidden_layers {
        // Real M0 signature (see layer_parity.rs): from_weights(weights, args, quant, layer_idx)
        layers.push(TransformerBlock::from_weights(&weights, &args, &quant, i as usize)?);
    }

    let norm = GemmaRmsNorm::from_weight(
        get_weight(&weights, "language_model.model.norm.weight")?, args.rms_norm_eps);

    Ok(Gemma4TextModel {
        embed_tokens, embed_scale: (args.hidden_size as f32).sqrt(),
        layers, norm, final_logit_softcapping: args.final_logit_softcapping,
        layer_types: args.layer_types.clone(), sliding_window: args.sliding_window, args,
    })
}
```

## Task 3: `model.rs` — `forward` → logits(含 mask、tied lm_head、softcap、last-logits)

**Files:** Modify `gemma4-mlx/src/model.rs`.

- [ ] **Step 1: 实现 forward**

```rust
use crate::mask::{full_causal_mask, sliding_window_mask};

impl Gemma4TextModel {
    /// tokens: [B, L] (i32). 返回 logits。`last_only=true` 时只对最后一位反投影
    /// (vocab=262144 极大,prefill 时务必 true 以省内存,spec §5.11)。
    #[allow(non_snake_case)]
    pub fn forward(&mut self, tokens: &Array, last_only: bool) -> Result<Array> {
        let L = tokens.shape()[1];
        // 嵌入 + 缩放
        let mut h = self.embed_tokens.forward(tokens)?;        // [B,L,hidden]; 确认 QuantizedEmbedding forward API
        h = h.multiply(Array::from_f32(self.embed_scale))?;

        // 预构造两种 mask(prefill, offset=0)。short L < window 时二者等价但仍按类型构造。
        let full_mask = full_causal_mask(L, 0)?;
        let sliding_mask = sliding_window_mask(L, 0, self.sliding_window)?;

        for (i, layer) in self.layers.iter_mut().enumerate() {
            let m = match self.layer_types[i] {
                LayerKind::Global => &full_mask,
                LayerKind::Sliding => &sliding_mask,
            };
            h = layer.forward(&h, m)?;          // block.forward(x, mask) — M0 signature
        }

        h = self.norm.forward(&h)?;
        if last_only {
            // 取最后一位: h[:, -1:, :]  (用 IndexOp; 确认 mlx-rs 负索引/切片写法)
            h = h.index((.., (L-1)..L, ..));    // [B,1,hidden]
        }

        // tied lm_head: 用 embed_tokens 反投影。QuantizedEmbedding::as_linear(&h)
        let mut logits = self.embed_tokens.as_linear(&h)?;     // [B, *, vocab]

        // final logit softcap: 30 * tanh(logits/30)
        let cap = self.final_logit_softcapping;
        if cap > 0.0 {
            logits = mlx_rs::ops::tanh(&logits.divide(Array::from_f32(cap))?)?
                .multiply(Array::from_f32(cap))?;
        }
        Ok(logits)
    }
}
```
(ADAPT to real mlx-rs API: `QuantizedEmbedding::forward` for token lookup, `as_linear` for tied projection, `IndexOp` slice syntax, `ops::tanh`/`divide`/`multiply`. Cross-check against `qwen3-mlx/src/model.rs` tied-embedding path (`embed_tokens.as_linear(&out)`) and softcap if present elsewhere. If `as_linear` needs the un-sliced hidden, slice first as shown.)

```python
"""Full-model logits golden via mlx-vlm (same 4-bit weights, correct internal masks).
Usage: python scripts/dump_gemma4_logits.py <MODEL_DIR> <OUT_DIR>
Outputs: tokens.npy [1,L] int32; logits_last.npy [1,vocab] f32; argmax_last.json
"""
import sys, json
from pathlib import Path
import numpy as np, mlx.core as mx
from mlx_vlm import load

model_dir, out_dir = sys.argv[1], sys.argv[2]
out = Path(out_dir); out.mkdir(parents=True, exist_ok=True)
model, _ = load(model_dir)
tm = model.language_model.model

# Fixed short token sequence (arbitrary valid ids; avoid special-token edge cases).
tokens = mx.array([[2, 1024, 2048, 4096, 8192, 16384]], dtype=mx.int32)  # [1,6]
h = tm(tokens)                         # full text model forward (builds correct masks internally)
h = tm.norm(h) if hasattr(tm, "norm") else h   # if __call__ already applies norm, skip
# logits via tied embedding:
logits = tm.embed_tokens.as_linear(h)  # confirm path; else use model.language_model.lm_head
# apply final softcap if model does it outside:
cap = getattr(model.config.text_config, "final_logit_softcapping", 0.0) or 0.0
if cap: logits = mx.tanh(logits / cap) * cap
mx.eval(logits)
last = np.array(logits[:, -1, :], dtype=np.float32)
np.save(out / "tokens.npy", np.array(tokens, dtype=np.int32))
np.save(out / "logits_last.npy", last)
(out / "argmax_last.json").write_text(json.dumps({"argmax": int(last.argmax()), "L": int(tokens.shape[1])}))
print("dumped; argmax(last)=", int(last.argmax()), "logit_absmax=", float(np.abs(last).max()))
```
